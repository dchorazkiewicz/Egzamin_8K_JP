## Virtualenv (venv) – obowiązkowe

- Zawsze używaj Pythona z lokalnego środowiska `venv` w tym repo: `./venv/bin/python`.
- Instaluj zależności wyłącznie do tego `venv`: `./venv/bin/pip install -r requirements.txt` (lub konkretne paczki).
- Nie używaj systemowego `python`, `pip` ani globalnych instalacji.
